8 月 OS4
完整订阅形态(支付功能全集)

功能限制 — 明确免费功能 / 付费功能边界,对付费功能提示

  • Native 订阅入口 — 「我的」入口 + 引导卡片 + 限时活动横幅
  • 用量中心 — 总额度 + 分模型 + 分功能 + 用量趋势曲线
  • 套餐与支付 — 多档对比(基础 / 进阶 / Pro)+ 年付/月付 + 自动续费管理
  • 账单与发票 — 历史订单 + 发票申请 + 退款申请
  • 智能触达 — 用量预警 + 续费提醒 + 临期挽留 + 个性化推送
  • 会员权益 — 高级模型解锁 + 会员标识 + 优先排队
